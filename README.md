# Flutter Projects

This repository contains Flutter projects developed as part of the Digital Skills Training Program (DSTP). Each project is organized in its own folder with dedicated code, assets, and documentation.

---

## Projects in this Repository

| Project Folder | Description |
| :--- | :--- |
| [Assignment 1 StudyNest](./Assignment%201%20StudyNest/studynest) | StudyNest mobile app UI from Figma with interactive session adding, date/time pickers, and clean layout (Assignment 1). |
| [expense_tracker](./expense_tracker) | Personal finance and expense tracker app focusing on Figma UI design implementation and core functionality. |
| [my_calculator](./my_calculator) | Calculator app for basic arithmetic operations. |
| [to_do_app](./to_do_app) | To-do app for creating, updating, and managing tasks. |

## Getting Started

To run any project:

1. Clone the repository:
   ```bash
   git clone https://github.com/Muqadas1234/Flutter_projects.git
   ```

2. Navigate to the desired project folder:
   ```bash
   cd "Assignment 1 StudyNest/studynest"
   # or
   cd expense_tracker
   # or
   cd my_calculator
   # or
   cd to_do_app
   ```

3. Install packages and launch:
   ```bash
   flutter pub get
   flutter run
   ```
