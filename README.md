## Getting Started

To run any project:

1. Clone the repository:
   ```bash
   git clone https://github.com/Muqadas1234/Flutter_projects.git
   ```

2. Navigate to the desired project folder:
   ```bash
   cd expense_tracker
   # or
   cd my_calculator
   # or
   cd to_do_app
   ```

3. Install packages and launch:
   ```bash
   flutter pub get
   flutter run
   ```
